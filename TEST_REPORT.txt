AnimeDubberMac v3.2 release validation

Release-specific checks:
- Python source parse/compile preflight
- Existing core/character/FFmpeg/orchestration tests
- yt-dlp executable selection test (must use current venv Python module)
- automatic retry test: standard -> web_embedded -> HLS
- IPv4 fallback flag test
- shell syntax checks
- GUI/CLI import checks
- ZIP extraction + re-test

Network-dependent YouTube downloading cannot be exercised in the offline build
environment, so v3.2 validates command construction and retry behavior with a
deterministic fake runner. The Mac setup installs a current app-local yt-dlp
(master when reachable, PyPI fallback otherwise) and prints the exact version.

v3.4 transcript/TTS robustness fix
- Inspected v3.3 failure where Whisper emitted reversed and 20ms timestamp-token fragments.
- Added sanitize_segments() before cached/new transcripts reach SRT, character analysis, translation, or TTS.
- Collapses obvious duplicate micro-segments, removes punctuation-only fragments, and repairs non-positive/too-short timing to >=180ms.
- write_srt() now refuses invalid non-positive ranges.
- TTS WAV output is ffprobe-validated immediately; zero-sample filtered WAVs are retried without timing/pitch compression before failing.
- Existing transcript_zh_v3.json cache is sanitized on resume, so a full retranscription is not required just to apply the repair.
- Unit tests: 24 passed, 1 macOS-only TTS test skipped in Linux test environment.
